# HCV preset sources

Research use only.

## Reference

- Accession: **NC_004102.1** (Hepatitis C virus genotype 1, isolate H77)
- Source: NCBI Nucleotide / RefSeq
- Protein: polyprotein `POLY:342-9377` (standard genetic code).

## Primers

No tiled public scheme is bundled. The usual literature method is a single
~9 kb amplicon with genotype-specific reverse primers (Bull et al. 2016,
https://link.springer.com/article/10.1186/s12864-016-2575-8). The preset runs
with no primer trimming by default (`requires_primer_bed: false`) and still
accepts an optional user `--primer_bed`.

## Taxonomy

- NCBI taxid **11103** (Hepacivirus hominis / hepatitis C virus)
